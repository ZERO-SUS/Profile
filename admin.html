First time? One-time setup (Firebase)
  1. Create a project at Firebase Console.
  2. Add a Web App and paste its keys into js/firebase-config.js.
  3. Enable Authentication → Email/Password, then add your Gmail + a password as a user.
  4. Create a Firestore database and paste the rules from ADMIN_GUIDE.md.
